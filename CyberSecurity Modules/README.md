# Thread-Safe Banking System (Python)

##### Overview
This project implements a thread-safe banking system in Python.  
It demonstrates secure coding practices, advanced object-oriented principles, and concurrency control.  
The system was developed as part of MSc Cybersecurity coursework at the University of Essex Online.

--------------------------------------------------------

##### Project Structure

BankSystemProject/
  README.md
 
  src/                  **#Actual source code directory for assignment**
    bank/
      account.py        # BankAccount class (core logic - ***assignment's code***)
      exceptions.py     # Custom exceptions - ***assignment's code*** (InvalidAmountError, InsufficientFundsError)

------------------------------------------------------

##### Features
- **BankAccount class** with deposit, withdraw, and get_balance methods.
- **Thread safety** using `threading.Lock` to prevent race conditions.
- **Deadlock prevention** via consistent lock ordering.
- **Custom exceptions** for invalid amounts and insufficient funds.
- **Unit tests** validating correctness under functional and concurrent scenarios.
